产品概述

梭哈工具台是基于 Python 3.13 + PySide6 的本地原生 GUI 桌面效率工具箱，把日常零散的本地工具集中到一个窗口，免去四处寻找的麻烦。数据本地存储（SQLite），文件夹分发、启动快。除主界面外，还提供全局能力：超级剪切板（Ctrl+Shift+V）、聚合搜索（双击 Ctrl）、悬浮便签、自动更新、自定义快捷键、开机自启。DeepSeek 问答与记忆大师 AI 导入功能需要联网。

🎓 记忆大师

自建知识词典 + 桌面悬浮卡片定时滚动记忆，适合背单词、记短语、记知识点。

知识库

  • 三类条目：单词（目标语言 + 音标 + 释义）、短语/短句（目标语言 + 释义）、知识点（标题 + 内容）
  • 左侧分类管理，自定义图标，右键重命名/删除（删除时可选移入未分类或一并删除条目）
  • 条目支持搜索、显示/隐藏已掌握、右键编辑/标记掌握、批量删除

导入导出

  • 支持 JSON / Excel 导入，可指定分类或按文件中的分类列自动归类
  • 多选或全量导出（JSON / Excel），提供导入模板下载
  • 🤖 AI 导入：填写类型、分类、数量、目标主题、附加要求，由 DeepSeek 自动生成并去重导入（复用 DeepSeek 问答的 API Key，需联网）

学习计划

  • 选择滚动分类（可多选，不选=全部），每次抽取 20 或 50 条
  • 卡片显示时长 1 或 5 分钟
  • 「启用记忆卡片」开关实时生效，无需点保存

悬浮记忆卡片

  • 桌面浮窗，可拖动到任意位置，底部滑条调节透明度
  • 单词/短语显示 🔊 朗读 按钮（离线发音，只读内容，不读音标释义）
  • ✅ 已掌握（从本批移除）、▶ 下一个（切换后重新计时）
朗读说明：使用系统离线语音（SAPI5），需系统已装语音包，无需联网。

🔐 密码管理器

生成密码

  • 添加多个必须包含的字符串段（➕/➖ 增删），每段可单独保留原始大小写
  • 设置总长度、字符类型（大写/小写/数字/特殊符号）
  • 三个生成选项：打散插入段 / 保留大小写 / 最终整体乱序
  • 实时强度指示（弱/中/强/极强），📋 复制或 💾 保存到管理器

保存到管理器

一个密码可创建多个独立条目（每条有独立标题/分类/备注/网址），➕ 添加另一个条目，保存时逐条创建，每条均可独立搜索。

密码管理列表

  • 左侧分类栏（自定义 emoji 图标），右键重命名/删除（可选释放或级联删除）
  • 条目右侧显示关联网址的图标，双行自适应
  • 右键菜单：复制密码、去网站使用密码（先复制密码再打开浏览器）、编辑、删除、🔀 派生密码
  • 全局去重：密码+URL 组合重复时跳过，跨分类检查

派生密码

右键 → 🔀 派生密码，以当前密码为基础打开多条目创建弹窗，可新建共用相同密码的多个独立条目。

导出 / 导入

功能说明
导出明文JSON 格式，不含图标数据，可保存到文件或复制到剪贴板
导出加密SUOHA: 前缀的加密文本，需在「解密」Tab 或本工具还原
导入支持文件或剪贴板，明文/加密自动识别，重复条目跳过

📋 进程管理器

从「一指神功」点击「📋 进程管理器」按钮打开。

  • 列出系统所有进程，颜色区分：🟢 用户进程、⚫ 系统进程、🔴 高危进程

四象限

重要且紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急，新建时选择象限。

🔄 闭环管理

用于管理需要长期跟进、闭环日期暂不确定的事项——区别于「待办管家」关注的有明确截止时间的任务。适合把一件事的来龙去脉、过程进展串成时间线，便于日后回溯。

新建事项

  • 必填：事件名称、开始日期（默认当前时间）、事件背景（长文本）
  • 可选关联信息：链接（只显示备注、单击跳转、可复制 URL）、目录位置（单击打开、可复制绝对路径）、图片（Ctrl+V 粘贴、单击预览）、关联人员（姓名+工号，可复制、可增删）
  • 创建后进入只读预览，点「修改」可再次编辑各项

进展时间线

  • 随时「新增进展」：日期、是否里程碑、进展详情，以及与事项相同的四类关联信息
  • 历史进展可逐条「展开 / 折叠」，也可「全部展开 / 全部折叠」；折叠时只显示日期 + 摘要（过长自动截断）
  • 每条进展可单独修改、删除

闭环

点「闭环」填写闭环结论（默认标记为里程碑），闭环后事项转为只读存档，不能再编辑。

分类与回收站

事项分为「进行中 / 已闭环 / 回收站」三类管理。删除为软删除，回收站可恢复或彻底删除。

回溯导出

  • 勾选：是否包含关联信息 / 是否仅导出里程碑 / 是否包含关联人员
  • 选择本地时区与目标时区，导出时自动把整条时间线换算到目标时区
  • 生成正式、结构化、无表情符号的纯文本报告，可保存为 .txt 或一键复制到剪贴板

🧠 记忆长廊

  • 剪切板监听开启后，复制的文字 / 图片 / 文件自动归档到记忆长廊
  • 左侧日历按天浏览：有记录的日期为彩色加粗，当前查看的那天用醒目浅蓝底色块高亮
  • Chrome 式滚动跨天：文本 / 图片 / 文件三个分页都可上下滚动连续翻看相邻日期，左侧日历随之联动定位
  • 支持全文搜索；超级剪切板（Ctrl+Shift+V）也可快速检索并上屏

📊 数据看板

工具使用频率、待办趋势、象限分布、字数统计，支持按天/周/月切换。

固定与分组

  • 分组内固定记录：Enter 原格式上屏、Tab 纯文本上屏；右键可取消固定 / 移动到其它分组 / 粘贴为 .txt。
  • 设置中可开启「固定记录置顶」，固定记录按分组分段显示在最前。

数据同步

在设置页面「数据同步」区域：

  • 填写备份目标路径（如 D:/Backup/suoha.db），点击 📂 浏览选择
  • 勾选「每天自动同步」，程序启动时检查，每天最多同步一次
  • 点击「🔄 立即同步」手动触发，状态栏显示结果
  • 每次同步会在目标目录额外保留一份带时间戳的历史快照

常见问题

Ctrl+Shift+V 没反应？

确认设置中「超级剪切板」已启用，且已安装 keyboard 库（pip install keyboard）。若热键被其他程序占用，可在设置中禁用后重启。

Ctrl+Shift+V 后输出了字符 v？

更新到最新版（已改用 Windows RegisterHotKey API，无按键泄漏）。

DeepSeek 问答提示需要 API Key？

在工具栏的 Key 输入框填入 DeepSeek API Key（sk- 开头），会自动保存。该功能需要联网。

记忆卡片朗读没声音？

朗读使用系统离线语音（SAPI5），确认系统已安装语音包。语速默认已调慢。

记忆大师 AI 导入失败？

AI 导入复用 DeepSeek 的 API Key，需先在 DeepSeek 问答中填写，且需要联网。

密码管理器搜不到某个条目？

每个条目是独立记录，确认标题或网址已填写。密码相同但 URL 不同的条目是独立可搜索的。

C盘清理提示无权限？

C:\Windows\Temp 需要管理员权限，以管理员身份运行工具台即可。

进程管理器显示权限不足？

系统进程需要管理员权限才能终止，以管理员身份运行后可操作。

数据迁移？

复制 .db 文件到新位置，在设置页面修改「数据库路径」后重启即可。
